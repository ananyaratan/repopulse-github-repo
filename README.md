🚀 RepoPulse

Discover Open-Source Projects. Find Issues. Start Contributing.

RepoPulse is a platform designed to help developers discover open-source repositories, find beginner-friendly contribution opportunities, and improve their open-source contribution journey with AI-powered guidance.

✨ Features

* Discover & Match: Explore open-source repositories based on your interests and skills.
* Repository Catalogue: Browse repositories and view information such as technology stack, stars, and good first issues.
* Prompt Engineering: Explore prompt engineering resources and opportunities.
* AI Mentor Chat: Get guidance and assistance throughout your open-source contribution journey.

🛠️ Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Node.js

💻 Getting Started

Follow these steps to run RepoPulse locally.

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder

cd repopulse

3. Install dependencies

npm install

4. Start the development server

npm run dev

Open http://localhost:3000 in your browser.
